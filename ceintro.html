Perguntas Frequentes

Preciso pagar mensalidade no plano Intro?

Não! O plano Intro é um pagamento único de R$ 49,90 e você tem acesso vitalício às funcionalidades incluídas no plano. Funcionalidades do plano Padrão não estão inclusas.

Funciona no meu computador?

O plano Intro está disponível na versão desktop para Windows. O plano Padrão terá acesso via Desktop + Web.

Preciso de internet para usar?

No plano Intro, o software funciona 100% offline com dados salvos localmente. A internet é necessária apenas para fazer login na primeira vez.

Posso usar em mais de um computador?

No plano Intro, sua conta é para 1 usuário. O plano Padrão permitirá mais de 1 usuário. Basta fazer login em outro computador.

Quando o plano Padrão estará disponível?

O plano Padrão está em desenvolvimento e estará disponível em breve. Fique atento às nossas atualizações!
